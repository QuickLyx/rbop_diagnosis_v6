## 1. 动机与融合定义

现有评估链路（`trainer.py: evaluate_feature`）已是两层聚合：

```
窗口概率 ──同文件同通道平均──▶ 记录级概率 ──argmax──▶ 判类（1 条记录 = 文件×通道）
```

本文模拟只在末尾追加一层**完全同构**的平均：

```
p_file = ( p_DE + p_FE ) / 2        # 两通道记录级概率等权平均
判类 = argmax(p_file)               # 1 个文件 = 1 个结论
```

`p_DE`、`p_FE` 即 `predictions.csv` 的 `probabilities` 列。测试前向不变（无梯度、不更新 BN），不违反任何铁律。合法性依据：DE/FE 是**同一文件、同一故障状态**的两次同步测量，两通道数据在评估时天然都在手（`dataset.py` 本来就对每文件两通道都切窗），且协议 §6 自述的 transductive 设定（"先有一整批记录，再挑送检"）下现场本来就是一个文件只出一个诊断结论。

## 3. 发现二：通道间错误重叠极低

按文件级统计"该文件·run 上两通道的判对情况"（`ce` 臂 12 run 累计）：

| 来源 | 文件·run 总数 | 双通道同错 | 仅 DE 错 | 仅 FE 错 |
| --- | ---: | ---: | ---: | ---: |
| `12k_FE` | 420（35 文件×12 run） | **1** | 18 | 22 |
| `48k_DE` | 480（40 文件×12 run） | **5** | 40 | 0 |

至少一个通道出错的文件·run 共 41 个（`12k_FE`）/ 45 个（`48k_DE`），其中**双通道同错仅 1 个（`12k_FE`）与 5 个（`48k_DE`）**——约九成的单通道错误可被另一通道覆盖。这是融合有效性的直接结构证据，不是数值巧合：DE（驱动端）与 FE（风扇端）对同一故障的观测敏感性不同（外圈故障位置相对载荷方向不同时尤其明显），与轴承诊断的物理常识一致。

## 4. 主结果：记录级 vs 文件级

`ce` 与 `ce_mmd` 两臂、两来源，均值±总体标准差（括号内为 12 个 run 的最差值）：

| 来源 | 臂 | 记录级（现状判据） | 文件级（DE+FE 融合） |
| --- | --- | ---: | ---: |
| `12k_FE` | `ce` | 95.00%±1.37（min 92.86%） | **98.81%**±1.41（min **97.14%**） |
| `48k_DE` | `ce` | 94.79%±1.43（min 92.50%） | **98.54%**±1.23（min **97.50%**） |
| `12k_FE` | `ce_mmd` | 95.12%±1.23（min 92.86%） | 98.33%±1.83（min 94.29%） |
| `48k_DE` | `ce_mmd` | 94.69%±1.85（min 91.25%） | 98.33%±2.12（min 95.00%） |

判据线换算（若下一批以文件级 ≥95% 为判据）：

- `12k_FE`：35 个决策单元，需 ≥34/35（每 run 最多错 1 个文件）。`ce` 臂最差 run 恰为 34/35，**12/12 run 全部过线**。
- `48k_DE`：40 个决策单元，需 ≥38/40（最多错 2 个文件）。`ce` 臂最差 run 为 39/40，**12/12 run 全部过线**。
- `ce_mmd` 臂：`12k_FE` 有 1 个 run 为 33/35（94.29%），**差 1 个文件过线**；`48k_DE` 12/12 过线（最差 38/40，恰好压线）。

结论：**文件级判据下 `ce` 臂两来源全部 run 过线**——`12k_FE` 最差 run 恰好压线（34/35），`48k_DE` 最差 run 余 1 个文件（39/40）；均值层面每 run 平均只错 0.4–0.7 个文件。`ce_mmd` 略弱，与记录级结论（MMD 无净增益）一致。

## 附录：复算脚本

本文全部数字可用以下脚本从 `outputs/v6_round1/eval/` 复现（`python - <<'EOF'`，依赖仅标准库）：

```python
import csv, math
from pathlib import Path
from collections import defaultdict
import statistics as st

names = ['Normal', 'Ball', 'IR', 'OR']
def fused(rows, rule='mean'):                      # rows: {(file,ch):(true,probs)}
    by_file = defaultdict(lambda: [None, []])
    for (f, ch), (tru, p) in rows.items():
        by_file[f][0] = tru; by_file[f][1].append(p)
    ok = 0
    for f, (tru, pl) in by_file.items():
        s = [sum(p[i] for p in pl) / len(pl) for i in range(4)]   # 等权平均
        if rule == 'geo':
            s = [math.exp(sum(math.log(max(p[i], 1e-12)) for p in pl) / len(pl))
                 for i in range(4)]
        ok += (s.index(max(s)) == tru)
    return ok, len(by_file)

for src in ['12k_FE', '48k_DE']:
    rec, fus = [], []
    for d in sorted(Path('.').iterdir()):
        if not d.is_dir() or 'ce_adapt' not in d.name or not d.name.startswith(src):
            continue
        rows = {}
        for r in csv.DictReader((d / 'predictions.csv').open(encoding='utf-8')):
            p = [float(r[f'prob_{n}']) for n in names]
            rows[(r['file'], r['test_channel'])] = (int(r['true']), p)
        rec.append(sum(p.index(max(p)) == t for t, p in rows.values()) / len(rows))
        ok, n = fused(rows); fus.append(ok / n)
    print(f'{src}: 记录级 {st.mean(rec)*100:.2f}% (min {min(rec)*100:.2f}%) -> '
          f'文件级 {st.mean(fus)*100:.2f}% (min {min(fus)*100:.2f}%)')
```
